# strsweep

Goソース内の文字列リテラルを、パッケージごとの非公開定数へまとめるCLIデモです。Go標準ライブラリのみを使用し、外部通信・テレメトリ・対話入力はありません。

## ビルド

Go 1.25以上（標準ライブラリのディレクトリハンドル相対I/Oを使用）:

```sh
go build -o strsweep ./src/strsweep/cmd/strsweep
./strsweep --help
```

対応環境:
- Linux・macOS・BSD: scan / apply
- Windows: scanのみ。ACLをPOSIX権限ビットで安全に再現できないため、変更があるapplyは書き込み前に終了コード3で中止します
- JavaScript/Wasm・Plan 9: パス差し替え競合への保護が十分でないため、処理を中止します

## 使い方

```sh
# 読み取り専用: ファイル別の進捗表と候補一覧
./strsweep scan ./path/to/project

# 全候補を適用: --yesは必須（前後どちらでも指定可能）
./strsweep apply ./path/to/project --yes
```

進捗表はパス順で、検出・除外・対象の件数と状態、合計を標準出力へ表示します。候補一覧の値は引用・エスケープされるため、改行を含む文字列も1行で確認できます。Linux・macOS・BSD・Windowsでは標準エラーが端末の場合だけ走査中の1行進捗を表示します。他のOSとリダイレクト時には、通常の進捗表のみ出力します。

### 抽出と命名

- importパス、構造体タグ、既存const内の文字列、空文字列を除外します
- `_test.go`、生成コード、`vendor/`、`testdata/`、ドット始まりのディレクトリを除外します
- シンボリックリンクを辿りません。対象ルートやその祖先がリンクの場合もエラーになります
- 同じディレクトリ・パッケージの同じ文字列値を1定数に集約します
- ASCII英数字の先頭4語から`strFileNotFound`のような名前を生成します。英数字を含まない値にはSHA-256の先頭6桁を使います
- 値の辞書順で名前を割り当て、既存の識別子（ローカル変数も含む）や生成名との衝突に`2`、`3`…を付けます
- `strsweep_const.go`に、名前順・gofmt済みの定数を保存します
- 外部テストを除いて複数のパッケージが混在するディレクトリや、生成先が既存の利用者ファイルと衝突するパッケージはスキップします

### 安全性と再実行

生成ファイルの先頭の目印は次のコメントです。

```go
// Code generated by strsweep. DO NOT EDIT.
```

再実行時はこの目印で所有を確認し、以前の定数を保持します。同じ値は再利用し、新しい値だけを追加します。手動で改変され解釈できない生成ファイル、または既存生成名を隠す宣言がある場合はエラーにして変更を中止します。直後の2回目の適用は対象0件となり、ファイルを書き換えません。

全変更をメモリ上で生成・再構文解析してから、同じディレクトリ内の一時ファイルとバックアップを準備します。走査時のルート・パッケージ・ファイルの識別情報を確認し、固定したディレクトリハンドルを通して読み書きします。パスをリンクに差し替えても、リンク先へ書き込みを転送しません。書き込み直前に元データが変わっていないことを検査し、ファイルを置き換えます。

書き込み失敗時は、置換済みのファイルをまず`.strsweep-recovery-*`へ退避してから復元します。別の編集があればその編集を優先し、復元先に新しいファイルが現れた場合も上書きしません。排他的なハードリンク作成が使えないファイルシステムでは、安全でない代替処理を行わずバックアップを残します。

復元後も回復用スナップショットを所有者限定（0600）で残し、エラーに場所を表示します。実行前のバックアップも0600で作成します。エディタが開いたままのファイルへ遅れて書き込んでも、そのデータを失わないためです。該当するエディタを閉じ、現在のファイルと回復用データを確認した後で、不要な回復ファイルを利用者が削除してください。復元に失敗した場合は実行前のバックアップも保持します。

元ソースの置換箇所以外のバイトは変更せず、改行コード、末尾改行の有無、POSIX権限ビットを保持します。生成ファイルは元ソース・既存生成ファイルの権限の共通部分を使用し、他ユーザーに公開されていない値を含む場合は所有者限定に狭めます。内容が同じでも必要なら権限だけを狭めます。生成ファイルを更新する場合もその改行形式と末尾改行を保持します。所有者・拡張ACL・拡張属性の複製は保証しないため、それらに依存する特殊な共有環境では使用しないでください。

注意:
- 構文検証を行いますが、型チェックや対象プロジェクトのテストは実行しません。適用後に通常のビルド・テストで確認してください
- 全ファイルを一括したクラッシュ耐性のあるトランザクションではありません。強制終了・電源断時にも個々のファイルは丸ごと置き換えますが、途中まで適用された状態や一時ファイルが残り得ます
- 実行中のソースツリーを別プロセスで変更しないでください。通常の置換は直前確認とrenameの間を含めて、任意の同時編集に対するトランザクションではありません。復元時の回復用データは保持しますが、通常処理中の競合編集を完全には防げません。バージョン管理された作業ツリーでの実行を推奨します

### 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 成功（対象0件を含む） |
| 1 | 構文解析・検証・読み取りエラー。変更せず終了 |
| 2 | 引数エラー、`--yes`不足、対象ディレクトリがない |
| 3 | 書き込み失敗。復元結果を標準エラーで確認 |

エラーの原因を解消した後に再実行してください。

## 検証

```sh
go test ./...
go test -race ./...
go vet ./...
```

AST除外、命名と集約、生成定数の再利用、LF/CRLF/raw文字列、末尾改行、冪等性、構文エラー、生成先衝突、リンク、並行変更検出、書き込み失敗時の復元・バックアップ保持に加え、リンク差し替え競合、復元中の編集・開いたファイルへの遅延書込み、排他的復元、生成権限の縮小をテストしています。

試すには`test/fixtures/demo`を一時ディレクトリへコピーしてscan/applyしてください。テスト用の元データへ直接applyしないよう注意してください。
